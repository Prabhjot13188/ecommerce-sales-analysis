# E-commerce Sales Analysis

Python, SQL and Power BI Sales Analysis Project.

## 📊 Project Overview
This project analyzes E-commerce sales data using SQL for database & queries, Python for data cleaning & analysis, and Power BI for interactive dashboard.

## 🗂️ Database Structure
Created Ecommerce database with 4 tables:
- *customers* - customer_id, customer_name, city
- *products* - product_id, product_name, category, price
- *orders* - order_id, customer_id, order_date
- *order_items* - item_id, order_id, product_id, quantity

## 🔍 SQL Analysis Done
- Total Revenue
- Top Selling Product
- City Wise Sales
- Monthly Sales
- Best Customer

## 📁 Files in this Project
- sales_queries.sql - Database creation + All SQL queries
- ecommerce_python.ipynb - Python data analysis
- E-commerce dashboard.pbix - Power BI Dashboard

## 🛠️ Tools Used
- SQL (MySQL)
- Python (Pandas)
- Power BI
- GitHub

## 📈 Key Insights
- Found total revenue from all orders
- Identified top selling product and best customer
- Compared sales city-wise and month-wise
